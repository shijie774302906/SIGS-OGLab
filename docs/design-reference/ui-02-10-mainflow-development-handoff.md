## 3. 页面落地边界

### 02 项目/点位数据

- 读取工程、点位、数据质量、分层、参数和输出状态。
- 默认显示点位列表、当前点位概况、工作流进度和下一步。
- 不显示无意义场地示意图；除非有真实点位坐标并服务 2D/3D。

### 05 地层分层

- 读取 `LayerScheme`、`ClassificationEvidence`、当前点位和数据质量状态。
- 写入分层草稿和已采纳分层状态。
- `运行分层` 打开 `05B` 或直接运行默认方法，结果必须先是候选。
- `采纳为当前分层` 需要二次确认，采纳后成为参数解译默认输入。

### 06 参数解译

- 必须先有可用分层方案。
- 读取 `LayerScheme`、`MethodCapability`、`ParameterScheme`。
- 参数页按参数项组织：φ'、Su、γ、OCR、Dr 等。
- 方法选择器按输出参数、土类、输入可用性和用途等级过滤。
- 参数方案采纳后才允许进入成果输出。

### 07 成果输出

- 只消费已采纳 `LayerScheme` 和已采纳 `ParameterScheme`。
- 预检必须检查点位一致、数据阻塞、候选/研究结果混入、格式真实支持。
- HTML/Markdown 可作为优先支持格式；正式 PDF、DXF 在未实现前灰显或隐藏。

### 08/09 高级入口

- 08 用于方法接入、测试、能力声明和运行日志。
- 09 用于多方法试算和候选比较。
- 两者结果不能直接进入正式成果，只能发送到 05/06 作为候选或草稿。

## 4. 重新进入 handoff 前的强制条件

- 主流程默认页面不出现 `runner`、`registry`、`draft package`、`stdout`、`stderr`、内部路径和长日志。
- Explorer、Tabs、右侧属性、底部面板和状态栏必须证明继承已验收壳层，而不是重新绘制相似壳层。
- `05` 能看出当前分层是否已采纳。
- `06` 能看出当前使用哪套分层方案。
- `07` 能看出为什么能或不能生成成果包。
- 所有新增入口都有目标页、弹窗、面板或禁用状态。
- 1920 x 1080 下无明显文字重叠、状态截断、按钮溢出。
- 主流程页必须完成 Planning、UI/layout、Chinese user critique、Implementation/QA 审阅。
- `blocking` 未修复时，不得生成页面级 development handoff。
