## 1. 独立性与舍入

本记录从官方 PDF 印刷页 17–25 的公式逐项手工转录，用通用科学计算器按表达式计算，再把中间量和期望值录入 JSON。没有导入或调用 `src/features/jts/jtsT242Domain.ts`。测试只读取冻结 JSON 并与产品实现比较。

- 内部金值保留 IEEE-754 双精度计算器显示值，不先按 UI 小数位舍入。
- 断言采用相对误差 `1e-10 * max(1, |expected|)`。
- UI 显示舍入不得反向参与分类边界、迭代停止或方法域判断。
- 等号归属严格按表 7.1.2 和 7.2.8 的不等式。

## 4. 表 7.1.2 边界

`qn<=0.68MPa` 依次验证 `0.08/0.35/0.68` 的闭区间归属。`qn>0.68MPa` 的 Ic 等号归属为：`2.90->4, 2.60->5, 2.32->6, 1.87->7, 1.47->8`。

孔压路线取 `x=Delta u2/sigma'=0`，边界简化为：

```text
20.3 - 7.6 exp(0) = 12.7
31.0 - 11.6 exp(0) = 19.4
30 exp(0) = 30
70 exp(0) = 70
140 exp(0) = 140
```

所以等号依次归属于 4、5、6、7、8 类；略大于 140 进入 9 类。`x>2` 且已越过 4/5 边界进入 6 类；`x<-2` 且越过 6 类上界时孔压路线无分类。

有限 `qn<0` 按表的无下界字面规则归入 1 类，同时必须产生产品问题提示；参数计算仍拒绝 `qnet<=0`。
