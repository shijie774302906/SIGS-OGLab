## 3. 输入、单位与压力基准

普通输入只有：

```text
Depth(m) | qc(MPa) | fs(kPa) | u2(kPa, optional)
```

- `Depth/qc/fs` 必需且有限；首点允许 `Depth=0`，其原始证据保留但有效应力为 0 时归一化量不可用；后续深度严格递增。`u2` 要么整列存在，要么整列缺失。部分 `u2` 属于结构问题。
- 内部阻力和应力统一使用 `kPa`；7.2 中明确要求 `MPa` 的公式在调用前显式转换。
- CPTU 路线必须绑定探头有效面积比 `a`、水深、`u2HydrostaticDatum` 和 `testZeroDatum`。
- `u2HydrostaticDatum=total` 表示上传的 `u2` 已包含水深静水柱；`u2_mudline_relative` 先加 `gamma_w * waterDepth`，再进入 6.1.4。这只是孔压水柱参考，不是 JTS 6.1.5 的测试零点。
- `testZeroDatum=mudline` 是当前唯一可计算状态。`borehole_bottom` 必须拒绝并要求先按 6.1.5 同时修正 `u2` 与 `qc`；不得用水深替代引孔底深度。
- 无 `u2` 路线不询问水深。软件令水深项同时从总应力和静水压力中消去，只使用泥面以下土层深度建立近似有效应力。
- 默认海水重度 `10.0 kN/m3`；修改会使全部相关推导和下游结果变为 `需要更新`。

## 4. 原始修正与基础推导

普通导入把 `Depth/qc/fs/u2` 视为仪器已完成几何、零点和标定修正后的工程测值。若用户上传的是探杆长度、倾角或传感器原始读数，当前版本必须提示来源不适用，不能把它们直接当作普通模板列：

- 6.1.1：`Z=integral(Rh dl)`；单轴 `Rh=cos(alpha1)`；双轴 `Rh=(1+tan²(alpha2)+tan²(beta))^-1/2`。当前最小模板不接收倾角序列，因此不执行该修正。
- 6.1.2：`x'_d=x_d-Delta x_d`。当前最小模板不接收测试零点原始读数，因此要求来源已完成零点修正。
- 6.1.3：`X_d=K*x'_d`。当前最小模板不接收传感器标定系数，因此要求来源已完成标定修正。
- 6.1.6：消散初段陡降或上升不得静默平滑。原始序列保持不变；用户确认的计量起点或拟合修订另存为不可变修订。

### 4.1 JTS Qtn* 迭代

```text
Qtn* = CN * qt / pa
alpha = 1.338 - 0.249 * (Qtn*)^0.264
CN = min(1.7, (pa / sigma'_v0)^alpha)
pa = 100 kPa
```

按条文说明：`CN=1` 起算，重复计算 `Qtn* -> alpha -> nextCN`。若 `abs(nextCN-CN)<0.01`，把 `CN=nextCN`，用该新 `CN` 再计算并返回最终 `Qtn*` 与 `alpha`；否则令 `CN=nextCN` 继续。迭代次数是计算 `nextCN` 的轮数，比较符为严格 `<0.01`。最多迭代 100 次；未收敛、非有限或进入非正对数域时返回问题。

这不是现有 `qnet/pa/(sigma'/pa)^n` 的 Robertson-Wride 前置推导。后者保留自己的算法身份和历史结果，但不得显示为 JTS 6.2.8 或作为 JTS 默认分类证据。

### 4.2 6.3 成果曲线合同

- 深度为纵轴且向下，推荐 `1:100` 或 `1:200`，图幅不足时才缩小深度比例尺。
- 基础成果至少绘制 `qt/fs/u2/Rf/Bq` 与垂直深度关系；没有 `u2` 时 `u2/Bq` 轨道明确不可用。
- JTS 建议的数值比例关系为 `fs:u2:qt = 1:10:100`、`Bq:Rf = 10:1`；产品可为可读性提供单轨缩放，但必须保留单位和真实数值，不得通过归一化刻度伪装原值。
- 消散工作区提供 `u2-log(t)` 与 JTS 定义的 `U-log(t)`；宜同时提供 `qt-time`。时间必须大于 0，原始点与修订点分层显示。

## 5. 饱和重度与应力积分

```text
gamma_sat = 17.71 * qt(MPa)^0.066
qt > 30 MPa -> 默认采用 22 kN/m3，并记录使用了“可取 22”的产品选择
```

## 6. JTS 九类分类

Method IDs：

```text
JTS242-7.1.2-IC-CLASS-V1
JTS242-7.1.2-PORE-CLASS-V1
JTS242-7.1.2-COMPARE-V1
```

共同先按 `qn`（MPa）识别软土：

| 类别 | 范围 |
| --- | --- |
| 1 流泥 | `qn <= 0.08` |
| 2 淤泥 | `0.08 < qn <= 0.35` |
| 3 淤泥质土 | `0.35 < qn <= 0.68` |

表 7.1.2 对 1 类没有给 `qn` 下界。本产品逐字执行该归属：有限 `qn<0` 仍返回 1 类，但同时产生强提示 `请核对 qc、测试零点、压力基准和上覆应力`；参数归一化仍要求 `qnet>0`。不得静默返回无分类。

`qn>0.68 MPa` 时，`Qtn*-Fr/Ic` 路线为：

| 类别 | Ic 范围 |
| --- | --- |
| 4 黏土 | `Ic >= 2.90` |
| 5 粉质黏土 | `2.60 <= Ic < 2.90` |
| 6 粉土 | `2.32 <= Ic < 2.60` |
| 7 粉砂～细砂 | `1.87 <= Ic < 2.32` |
| 8 中砂～粗砂 | `1.47 <= Ic < 1.87` |
| 9 砾砂 | `Ic < 1.47` |

令 `x=Delta u2/sigma'_v0`，孔压路线为：

- 4：`Qtn* <= 20.3 - 7.6 exp(-x/6.23)`。
- 5：大于上述边界，且 `Qtn* <= 31.0 - 11.6 exp(-x/6.23)`。
- 6：大于上述边界，且 `x>2` 或 `Qtn* <= 30 exp(0.255|x|)`。
- 7：`-2<=x<=2`，且 `30 exp(0.255|x|) < Qtn* <= 70 exp(0.226|x|)`。
- 8：`-2<=x<=2`，且 `70 exp(0.226|x|) < Qtn* <= 140 exp(0.226|x|)`。
- 9：`-2<=x<=2`，且 `Qtn* > 140 exp(0.226|x|)`。
- `x<-2` 且未进入 4–6 时，孔压路线无分类，不得补造类别。

两路线同类为高置信候选；相差一类为带提示候选；相差两类及以上为待人工确认区间，不能提交当前自动方案。无 `u2` 时只运行 Ic 路线，并显示 `未使用孔压证据`。

## 7. 边界与代表值

- 7.1.3：`u2/Bq` 突变点可作为边界；上下层 `qc` 相差 1 倍以上时取超前与滞后深度中点；不足 1 倍时结合 `Rf/fs`。
- JTS 未给“突变”数值阈值。软件变化点阈值必须显示为软件规则，不能写成 JTS 公式。
- 厚度 `>1m` 且均匀：扣除上部滞后和下部超前范围后取均值。
- 厚度 `<1m`：软土取最小值；其他土取“较大值”。条文说明把“较大值”定义为最大值所在深度上下各 `20cm` 范围内的大值平均值；软件阈值必须透明。
- 强变化层按小层厚度加权：`Xbar=sum(xbar_i*h_i)/sum(h_i)`；先排除已确认异常。

## 10. 缺失、问题与恢复

- 缺少 `qc/fs`、非有限值、非递增深度、部分 `u2`：`存在问题`，不创建当前推导修订。
- 无 `u2`：允许 CPT 近似路线，不要求水深；孔压相关量和消散方法显示不可用。
- 孤立异常：允许明确保留或通过不可变排除修订排除，不改写原始值。
- 系数未确认：对应参数为 `待确认`，其他适用参数可继续。
- 超出合同数值域：不裁剪、不外推、不生成伪值；定位到输入、层或方法设置。
- 上游修订变化：旧结果保留为历史，当前链显示 `需要更新`，重新计算后才恢复。
