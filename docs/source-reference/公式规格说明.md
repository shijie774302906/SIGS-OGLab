# CPTU First-Pass Formula Spec

Date: 2026-06-17

This document defines the first real CPTU interpretation slice for the WinUI MVP.

Scope:

- single test-point run
- CPTU first-pass post-processing only
- real formulas for `q_t`, `q_net`, `sigma_v0`, `sigma'_v0`, `F_r`, `Q_tn`, and `I_c`
- first-pass soil-behavior grouping and richer first-pass metrics written into SQLite
- not yet covering `OCR`, `s_u`, `phi'`, liquefaction, or report formats beyond workbook export

## 1. Inputs

Per test point:

- `WaterDepth` from `TestPoints.WaterDepth`
- depth-ordered CPTU rows from `CptuRecords`
- measured channels:
  - `QcKpa`
  - `QtKpa`
  - `U2Kpa`
  - `SleeveKpa`

Runtime parameters for this first slice:

- `a_net` default `0.80`
- `gamma_t` default `18.0 kN/m^3`
- `gamma_w` default `10.05 kN/m^3`
- `sigma_atm` default `100.0 kPa`
- minimum effective stress floor default `5.0 kPa`
- iteration count default `4`

Notes:

- `gamma_t` is currently a user-controlled first-pass assumption used to establish stress normalization.
- Later slices can replace this with a derived `gamma_t` workflow from CPTU correlations.
- `WaterDepth` is required for offshore normalization. If it is missing, the run must fail closed instead of assuming `0.0`.

## 2. Formula Set

### 2.1 Corrected cone resistance

Primary source:

- `Mayne著作翻译.md`, Eq. `(1.1)`
- indexed in `Mayne_formula_index_initial.md` as `F001 line 57`

Formula:

`q_t = q_c + (1 - a_net) * u_2`

Implementation rule:

- if imported `QtKpa` exists, use it directly
- else derive `q_t` from `QcKpa` and `U2Kpa`
- else the row is `Undefined`
- do not silently fall back to raw `QcKpa` or `ConeMpa` alone

### 2.2 Hydrostatic pore pressure

Primary source:

- `Mayne著作翻译.md`, Eq. `(1.3)`
- indexed in `Mayne_formula_index_initial.md` as `F003 line 185`

Base formula:

`u_0 = h_w * gamma_w`

Offshore first-pass implementation:

- depth axis is treated as penetration depth below seabed
- `h_w = WaterDepth + z`
- therefore `u_0 = (WaterDepth + z) * gamma_w`

### 2.3 Total and effective vertical stress

Primary source:

- `Mayne著作翻译.md`, Eq. `(2.32)` for `sigma'_v0 = sigma_v0 - u_0`
- indexed in `Mayne_formula_index_initial.md` as `line 749`

First-pass implementation:

- `sigma_v0 = WaterDepth * gamma_w + z * gamma_t`
- `sigma'_v0 = sigma_v0 - u_0`
- apply floor: `sigma'_v0 = max(sigma'_v0, MinEffectiveStressKpa)`
- if `WaterDepth` is missing, reject the run before any interpretation result is written

Reason:

- the first slice needs a stable normalization path before a richer unit-weight model is added

### 2.4 Net cone resistance

Primary source:

- `Mayne著作翻译.md`, Section `3.2.1`

Formula:

`q_net = q_t - sigma_v0`

### 2.5 Friction ratio

Primary source:

- `Mayne著作翻译.md`, Eq. `(3.2)`
- indexed in `Mayne_formula_index_initial.md` as `line 927`

Formula:

`F_r (%) = 100 * f_s / (q_t - sigma_v0)`

Implementation rule:

- use `SleeveKpa` as `f_s`
- if `q_net <= 0` or `f_s <= 0`, mark row `Undefined`

### 2.6 Stress-normalized cone resistance

Primary source:

- `Mayne著作翻译.md`, Eq. `(3.3)`
- indexed in `Mayne_formula_index_initial.md` as `line 957`

Formula:

`Q_tn = (q_net / sigma_atm) / (sigma'_v0 / sigma_atm)^n`

### 2.7 CPT material index

Primary source:

- `Mayne著作翻译.md`, Eq. `(3.4)`
- indexed in `Mayne_formula_index_initial.md` as `line 963`

Formula:

`I_c = sqrt((3.47 - log10(Q_tn))^2 + (1.22 + log10(F_r))^2)`

### 2.8 Exponent iteration

Primary source:

- `Mayne著作翻译.md`, Eq. `(3.5)`
- indexed in `Mayne_formula_index_initial.md` as `line 969`

Formula:

`n = 0.381 * I_c + 0.05 * (sigma'_v0 / sigma_atm) - 0.15`

Bound:

- `n <= 1.0`

Implementation rule:

- initialize `n = 1.0`
- iterate 4 times
- if any intermediate value becomes non-positive for log use, mark row `Undefined`

## 3. First-Pass Soil Grouping

This MVP slice does not yet reproduce the full 9-zone chart numerically.

Source anchors:

- `Mayne著作翻译.md` states:
  - clean sands are generally `I_c` about `1` to `2`
  - silts are generally `I_c` about `2` to `3`
  - clays are generally `I_c >= 3`
  - `I_c = 2.6` is the drained vs. undrained demarcation

First-pass software grouping:

- `I_c < 2.05` -> `Sand-like`
- `2.05 <= I_c < 2.60` -> `Transitional`
- `2.60 <= I_c < 3.00` -> `Clay-like mixed`
- `I_c >= 3.00` -> `Clay-like`
- invalid or non-computable rows -> `Undefined`

This grouping is intentionally conservative and should be upgraded later to full chart-backed zone mapping.

## 4. Persistence

Run metadata:

- write one row to `InterpretationRuns`
- `MethodName = CPTU-RW-Ic-FirstPass`
- store runtime parameters in `ParameterJson`

Result rows:

- write one row per CPTU interval to `InterpretationResults`
- current fields used:
  - `DepthFrom`
  - `DepthTo`
  - `SoilType`
  - `Ic`
  - `QtKpa`
  - `SigmaV0Kpa`
  - `SigmaV0EffectiveKpa`
  - `QnetKpa`
  - `FrPercent`
  - `Qtn`
  - `GammaKnM3`

Unused for this slice:

- `SuKpa`
- `PhiDeg`
- `Confidence`

## 5. Known Limits

- only one test point per run
- uses constant `gamma_t` assumption instead of derived unit weight
- no chart-image zone lookup yet
- no OCR, `s_u`, `phi'`, liquefaction, or export formats beyond workbook output yet
- preview UI still shows a bounded result subset rather than the full profile
- export currently remains limited to workbook output rather than richer report formats
