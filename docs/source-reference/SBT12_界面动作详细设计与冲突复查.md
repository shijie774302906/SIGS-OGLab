## 1. 本文档解决什么问题

现有 `SBT12_实施设计说明.md` 已经说明了方向和切片，但还不够细，不能直接让开发者按屏幕区域和动作顺序落地。

本文档补充四类细节：

1. 页面怎么放：每个区域、控件、图、卡片、说明面板放在哪里。
2. 动作怎么发生：用户选择方法、切换 tab、选择深度、查看高亮、hover 信息时，界面和数据如何响应。
3. 每一刀具体做什么：每个切片改哪些区域、哪些文件、哪些行为，哪些事情禁止混入。
4. 是否冲突：与 `AGENTS.md`、`plan.md`、`界面布局排版规范.md`、当前代码和用户确认需求逐项复查。

本文档不替代总体设计。总体设计负责定义方向，本文档负责把方向拆到可开发、可复查的动作级别。

## 3. 页面总布局

### 3.1 页面结构

`测试解译` 页面继续保持三栏工作台结构。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 顶部：页面标题、当前点位摘要、运行按钮、运行状态摘要                         │
├──────────────────┬──────────────────────────────────────┬──────────────────┤
│ 左侧栏            │ 中间结果工作台                         │ 右侧栏            │
│ 点位/数据摘要      │ CPTU 曲线                              │ 解译方法选择       │
│ 输入/公式摘要      │ SBT 12区图                              │ 方法说明           │
│ 分层/深度索引      │ 分层参数                                │ 参数摘要           │
│                  │ 计算日志                                │ 运行与附件证据     │
└──────────────────┴──────────────────────────────────────┴──────────────────┘
```

保留三栏的原因：

- 左侧深度/分层选择是 SBT12 点高亮的触发源。
- 中间是主结果视图，SBT12 图和 CPTU 曲线需要共享当前点位和运行结果。
- 右侧用于说明当前选择的方法是不是正式落库方法，避免用户误读 SBT12。

### 3.2 中间 tab 顺序

当前阶段 tab 顺序：

```text
1. CPTU 曲线
2. SBT 12区图
3. 分层参数
4. 计算日志
```

后续加入 `参数解译` 后的顺序：

```text
1. CPTU 曲线
2. SBT 12区图
3. 参数解译
4. 分层参数
5. 计算日志
```

理由：

- `CPTU 曲线` 是原始曲线和当前解释曲线。
- `SBT 12区图` 是图上土体行为辅助判读。
- `参数解译` 是由公式计算得到的工程参数，逻辑上应在曲线和图上判读之后。
- `分层参数` 是汇总表。
- `计算日志` 是审计和异常记录。

本阶段不放空的 `参数解译` tab，因为空 tab 会让用户以为 φ、Su 已经有结果。

## 5. SBT12 绘图规则

### 5.1 坐标映射

绘图区像素范围：

```text
plotLeft
plotTop
plotWidth
plotHeight
```

x 轴映射：

```text
xPixel = plotLeft + (FR - 0) / (8 - 0) * plotWidth
```

y 轴映射：

```text
logY = log10(qtBar)
yPixel = plotTop + plotHeight - (logY - log10(1)) / (log10(1000) - log10(1)) * plotHeight
```

绘图前必须检查：

- `FR` 不是 NaN 或 Infinity。
- `qtBar > 0`。
- `0 <= FR <= 8`。
- `1 <= qtBar <= 1000`。

### 5.2 绘制层级

按以下顺序绘制，不能乱序：

1. 绘图区白底。
2. 图框边线。
3. x/y 轴网格线。
4. x/y 轴刻度和坐标标题。
5. SBT12 边界线。
6. SBT12 区号。
7. CPTU 普通散点。
8. 当前左侧选中深度/分层对应的高亮散点。
9. hover 提示。
10. 来源脚注。

原因：

- 白底和网格是读图基础。
- 边界线必须先于散点，否则散点会遮挡边界结构。
- 高亮点最后绘制，才能明显看出当前选择。
- hover 是临时浮层，不应改变选择状态。

### 5.3 颜色规则

主图颜色建议：

| 元素 | 颜色策略 |
| --- | --- |
| 绘图区背景 | `#FFFFFF` |
| 图框 | 项目线色 `WorkbenchLine` 或接近 `#D7E6EF` |
| 网格线 | 极浅蓝灰，低对比，仅辅助读数 |
| 边界线 | 多色、低饱和、线宽 `1.5-2.0` |
| 区号 | 深灰或黑色，避免彩色抢占含义 |
| 普通散点 | Nature-like 蓝绿色，如 `#2A9D8F`，透明度 `0.55-0.70` |
| 高亮散点 | 深蓝，如 `#0072B2`，加描边或放大 |
| 无效/超界点 | 不绘制，只计数 |

不使用彩色区域填充作为主视觉，因为用户要求 SBT 背景白色，边界线用多种颜色区分。

### 5.4 边界线来源

边界线只能来自：

```text
app_data/temp/excel-sbt/SBT_chart_series_cache.csv
```

运行时代码中应固化为只读定义，例如：

```text

Sbt12BoundaryPoint

```

禁止：

- 根据截图手动画曲线。
- 对曲线做无来源的平滑。
- 用 SBTn 9区或 Ic 分带边界替代 SBT12。

如果某条边界点缺失或无法闭合：

- 仍可绘制已知边界线。
- 不做该区的正式区号统计。
- 在说明面板显示 `部分区号统计待边界闭合复查`。
- 在 `Process7.md` 记录缺口。

## 6. 数据流与状态流

### 6.1 正式分类数据流

正式分类继续走现有路径：

```text
原始 CPTU 数据
-> CptuInterpretationService
-> qnet / Qtn / Ic
-> SoilType
-> InterpretationResults
-> 分层参数 / 导出 / 审计
```

该路径仍是：

```text
CPTU-RW-Ic-FirstPass
```

SBT12 不改变该路径。

### 6.2 SBT12 辅助判读数据流

SBT12 点云从当前可视化结果派生：

```text
当前 CPTU 可视化点
-> 读取 qt(kPa) 和 fs(kPa)
-> 计算 FR = 100 * fs / qt
-> 计算 qtBar = qt(kPa) / 100
-> 判断 Valid / OutOfRange / Invalid
-> 绘制标准范围内点
-> 统计有效、超界、无效
```

注意：

- SBT12 FR 必须用 `fs/qt`。
- 当前 `FrPercent` 用的是 `fs/qnet`，不能复用。
- `qtBar` 是把 `kPa` 转成 `bar`，即除以 `100`。

### 6.3 左侧选择到图上高亮

状态流：

```text
用户点击左侧深度/分层
-> 页面记录 selected layer/depth range
-> SBT12 图重新渲染或更新高亮层
-> 深度范围内点以高亮样式显示
-> 不改变正式分类
-> 不写数据库
```

高亮规则：

- 如果选中的是分层：高亮 `DepthMidM` 落在该层范围内的点。
- 如果选中的是单个深度行：高亮最接近或同深度范围对应点，具体规则按现有左侧索引模型确定。
- 高亮只影响视觉。

### 6.4 图上散点动作

本阶段散点不做反向选择。

允许：

```text
hover -> 显示 depth / FR / qt / Ic / 正式土类
```

禁止：

```text
click point -> 改变左侧分层/深度选择
click point -> 改变当前正式土类
click point -> 写入 SBT12 区号
```

如果 hover 实现复杂，可以推迟；但不能保留旧的点击反选。

## 9. 统计卡片

### 9.1 卡片位置

宽屏：

- 放在右侧说明面板中，位于 `坐标/边界/散点说明` 之后。
- 如果卡片很重要，也可以放在主图上方的横向条，但不能挤压主图。

中窄屏：

- 放在主图下方，说明文字之前或之后均可。
- 优先保持文字完整，不强行一行展示。

### 9.2 卡片内容

建议第一版：

```text
有效点
超界/无效
砂性倾向
黏性倾向
过渡/混合
```

不显示 `主导区号`。

统计口径：

| 卡片 | 口径 |
| --- | --- |
| 有效点 | 位于 `0 <= FR <= 8` 且 `1 <= qtBar <= 1000` 的点 |
| 超界/无效 | 超出标准图框或缺少有效 `qt/fs` 的点 |
| 砂性倾向 | SBT12 7-11 区的辅助聚合 |
| 黏性倾向 | SBT12 1-3 区的辅助聚合 |
| 过渡/混合 | SBT12 4-6、12 区的辅助聚合 |

如果区号多边形无法可靠闭合：

- 只显示有效点、超界/无效。
- 砂性/黏性/过渡卡片显示 `待边界复查`。
- 不猜百分比。
