# 参数解译 G2 曲线工作台合同

日期：2026-07-11  
状态：`已实现 / 已验证 / 三轨独立复查 P0=0 / P1=0`

## 1. 页面任务

G2 把已验证的 G1B 参数领域接到真实页面，不新增隐藏公式，也不把运行结果写成正式采用值。

```text
已提交分层精确修订
-> 建立参数方案并按地层配置 φ′p / suc 方法槽
-> 提交参数方案修订
-> 运行 qt / qnet / Qtn / Ic 前置推导
-> 显式确认层级贯入速率、排水与材料适用性证据
-> 选择文献 Nkt 或检查场地标定条件
-> 运行 φ′p / suc
-> 在共享深度轴上查看曲线、地层、行证据、层统计和问题
-> 可切换历史运行或重跑，不覆盖终态历史
```

## 2. 页面结构

- 左侧：现有固定五功能区工作流，不增加新导航。
- 中心首视：方法结论、共享深度曲线工作台和一个当前最强动作。
- 中心详情：`曲线 / 数据行 / 层统计 / 问题与历史` 视图，不同视图共用选中方法、运行、深度、来源行和地层。
- 右侧功能区：参数方案、方法切换、输入设置、证据确认、Nkt 来源、运行、取消、重跑和历史选择；继续支持隐藏。

## 3. 曲线与联动合同

首版四个稳定轨道：

1. `qt / qnet (kPa)`：同轨对比原始/推导锥阻和净锥阻。
2. `Qtn`：无量纲中间量。
3. `Ic`：无量纲行为指数。
4. `φ′p (°)` 或 `suc (kPa)`：随选中方法切换，可叠加同方法上一次完成运行。

联动规则：

- 所有轨道使用同一深度范围、分层背景、地层边界和选中深度线。
- 点击曲线点选中 `sourceRowId`，数据表滚动/高亮同一行，右侧显示该行方法状态和 reason codes。
- 点击层背景或层统计选中同一 `layerId`，曲线与表格都保留完数据，只改变强调和定位。
- 不可用、无效或试算值不得使用成功色伪装成当前结果。
- 曲线范围从可见数据计算，不使用隐藏截断；缺值断开曲线而不连线补齐。

## 4. 对象与状态

- 参数方案：`working -> current -> history/stale/deleted`，只有已提交精确修订可以创建运行。
- 前置推导：`queued -> running -> completed/failed/cancelled/invalidated`。
- 方法运行：`queued -> running -> completed/failed/cancelled/invalidated`，终态追加保留。
- 证据：每次确认创建不可变修订；运行冻结精确证据修订引用。
- 历史查看：只改变页面选中运行，不改变当前参数方案或下游对象。

## 5. Feature Coverage Gate

| 用户动作 | 对象 | 正常结果 | 可能事件 | 恢复路径 |
| --- | --- | --- | --- | --- |
| 进入参数页 | 分层精确修订 | 载入深度/层上下文 | 未检查、无当前分层、修订过期 | 数据检查或地层分层 |
| 建立方案 | 参数方案 | 按 sand/clay 层生成方法槽 | 无已分类目标层 | 返回分层设置工程土组 |
| 修改输入设置 | 方案草稿 | 范围内保留为草稿 | 数值越界或非数值 | 定位对应输入 |
| 提交方案 | 不可变修订 | 成为当前精确参数输入 | 上游变化、版本冲突 | 丢弃失效编辑并基于最新分层新建 |
| 运行前置推导 | 推导运行 | 生成 qt/qnet/Qtn/Ic | 行输入无效、qnet 非正、缺行 | 返回数据导入/检查定位行 |
| 确认方法证据 | 层证据修订 | 每层冻结速率/排水/材料证据 | 缺失、冲突、超出来源范围 | 右侧修正或保留试算状态 |
| 选择 Nkt | Nkt 设置 | 文献起始假设或场地标定 | 缺 CAUC/CIUC 修订或匹配对 | 选文献起始假设，或先补场地试验 |
| 运行方法 | 方法运行 | 生成行值、层统计、问题与曲线 | 不适用、缺证据、输入无效 | 定位证据、行或地层 |
| 取消/重跑 | 开放或终态运行 | 取消无部分结果；重跑追加历史 | 迟到完成、旧页签冲突 | 取消优先；精确 CAS 拒绝过时提交 |
| 点击曲线/表格 | 行与地层选择 | 同步高亮和证据详情 | 历史运行行集不同 | 按运行冻结行集显示，不强行对齐当前数据 |

## 6. Event Matrix

```text
Event: 无已提交当前分层
Detection: getCurrentParameterSource = deny
User-facing state: 尚不能建立参数方案
Available actions: 返回地层分层
Disabled actions: 方案提交、推导、方法运行
Recovery path: 地层分层 -> 提交精确修订
Acceptance evidence: 页面显示精确原因和返回动作
```

```text
Event: 场地标定 Nkt 条件不足
Detection: 无当前 CAUC/CIUC 试验修订、无匹配对或所属不一致
User-facing state: 存在问题，明确缺少对象
Available actions: 切换文献 Nkt=12；查看缺失条件
Disabled actions: 把场地标定写入当前方法运行
Recovery path: 后续试验证据入口，或显式选文献起始假设
Acceptance evidence: 不可运行 + 可见缺失说明
```

```text
Event: 上游分层修订变化
Detection: exact ParameterSourceLineage mismatch
User-facing state: 方案、推导和方法运行过期；历史保留
Available actions: 查看历史；基于最新分层新建参数方案
Disabled actions: 用过期方案重跑或写入当前结果
Recovery path: 地层分层 -> 最新修订 -> 新参数方案
Acceptance evidence: 旧运行仍可读，新运行被禁止
```

```text
Event: 行值不适用或无效
Detection: ParameterMethodResultStatus != Valid/ValidWithNotice
User-facing state: 曲线断开或使用问题标记，表格保留 reason codes
Available actions: 选中行、层或证据定位
Disabled actions: 显示为正常绿色结果
Recovery path: 右侧证据/方法或返回数据导入
Acceptance evidence: 曲线、表格、问题数与运行摘要一致
```
