# 新建项目与项目集合事件合同

Date: 2026-07-09

Status: `active contract / implementation guide`

## 1. Purpose

这个合同把“新建项目”从单个输入框扩展为完整项目集合事件。项目是工作流容器，不只是名称字段。

核心结构：

```text
项目集合
-> 新建 / 打开 / 切换 / 重命名 / 删除项目
-> 当前项目固定工作流
   项目/点位数据 -> 数据导入 -> 数据检查 -> 地层分层 -> 参数解译 -> 成果输出
```

## 2. Product Position

项目入口负责：

- 管理多个项目容器。
- 让用户创建、打开、切换、重命名、删除项目。
- 保证每个项目进入后都有同一套固定工作流。
- 保证每个项目的导入、检查、当前页面状态彼此独立。

项目入口不负责：

- 复杂项目档案管理。
- 场址、业主、坐标系等完整工程资料。
- 生产级持久化。
- 正式保存或桌面端同步。

## 3. Object Lifecycle

| Object | Created By | Updated By | Consumed By | States |
| --- | --- | --- | --- | --- |
| 项目集合 | App 启动 | 新建 / 删除 | 项目入口页 | 空集合 / 有项目 / 当前打开 |
| 项目 | 新建项目 | 重命名 / 删除 / 打开 | 固定工作流 | 草稿项目 / 当前项目 / 已关闭 / 待删除 |
| 项目工作流状态 | 项目创建时初始化 | 导入、检查、导航动作 | 六页工作流 | 项目/点位数据 / 数据导入 / 数据检查 / 地层分层 / 参数解译 / 成果输出 |
| 项目导入草稿 | 项目创建或文件上传 | 数据导入页 | 数据检查页 | 空草稿 / 可检查 / 存在问题 / 需重新检查 |
| 项目检查状态 | 运行数据检查 | 重新检查 / 导入变更 | 地层分层 | 未检查 / 无问题 / 存在问题 / 需重新检查 |

## 4. User Actions

| Action | Intent | Object Changed | Next Handoff |
| --- | --- | --- | --- |
| 查看项目集合 | 找到已有项目或创建新项目 | none | 选择项目或新建项目 |
| 新建项目 | 创建新的 CPT 解译工作容器 | Project + ProjectWorkflowState | 打开该项目 |
| 打开项目 | 进入该项目固定工作流 | activeProjectId | 当前项目的工作流状态 |
| 切换项目 | 在多个项目之间切换 | activeProjectId | 切换到目标项目上次状态 |
| 重命名项目 | 修正或更新项目名称 | projectName / updatedAt | 项目列表和工作台标题同步 |
| 删除项目 | 移除不需要的浏览器内项目 | projects | 回到项目集合或切换剩余项目 |
| 返回项目集合 | 从工作流回到项目管理 | activeProjectId | 项目集合页 |

## 6. Page Surface

### Project Hub

Center:

- 项目集合标题。
- 新建项目表单。
- 项目列表表格。
- 每行项目显示：项目名称、项目状态、点位/导入/检查摘要、更新时间、操作。

Right dock:

- 当前集合统计。
- 新建项目入口。
- 当前选中项目动作：打开、重命名、删除。

### Project Workspace

Left navigation:

- 固定六页工作流。
- 顶部提供返回项目集合。
- 显示当前项目名。

Each project owns independent:

- active route
- selected point
- import draft
- check run
- checked draft version
- selected issue
- selected mapping field

## 7. Implementation Steps

1. 建立 `ProjectWorkspace` 状态模型。
2. 新增项目集合页。
3. 支持新建项目并自动打开。
4. 支持打开/切换项目。
5. 支持重命名项目。
6. 支持删除项目，包含删除当前项目和最后一个项目。
7. 将现有单项目工作流状态迁移到当前项目 workspace。
8. 用 Playwright 验证多项目人类 flow。

## 8. Acceptance

Playwright must prove:

- 从空项目集合创建项目。
- 创建第二个项目。
- 项目列表显示多个项目。
- 打开项目后出现固定六页工作流。
- 重命名项目后列表和工作台标题同步。
- 删除项目后列表更新。
- 切换项目时每个项目保留自己的工作流状态。
- console/page errors 为空。

Evidence:

- screenshots at `1440x900` and `1920x1080` where relevant.
- `flow-run.json`.
- project names generated during test.
- active project before/after switch.
